# library/

Ten program templates for release 1 (build-plan s7.1). Shape and field meanings:
`docs/program-format.md`. Machine check: `python3 library/check.py`.

Structure only, written in our own words from a freely published source and
credited by name (research/16 "The licence rule"). No program text is copied.

| File | Template | Origin | Status |
|---|---|---|---|
| `gzclp.json` | GZCLP | Cody Lefever (GZCL method), r/Fitness wiki write-up | present |
| `bbr.json` | r/Fitness Basic Beginner Routine | r/Fitness wiki | present |
| `bwf-rr.json` | r/bodyweightfitness Recommended Routine | r/bodyweightfitness | present |
| `phul.json` | PHUL | Brandon Campbell, muscleandstrength.com | present |
| `ppl-metallicadpa.json` | Metallicadpa PPL | u/Metallicadpa, r/Fitness wiki archive | present |
| `nsuns-lp.json` | nSuns 5/3/1 LP | u/sunsun9m9 and the r/nSuns community | present |
| `kettlebell-wiki.json` | r/kettlebell wiki programming | r/kettlebell wiki | present |
| `easy-strength.json` | Easy Strength | Dan John | present |
| `couch-to-5k.json` | Couch to 5k | Josh Clark, 1996; NHS free derivative | present |
| `otago.json` | Otago Exercise Programme | University of Otago falls-prevention group | present |

Five categories ship no template and take the s7.2 refusal script instead:
rings calisthenics, dedicated loaded carries, named-restriction mobility,
in-season maintenance, full-body hypertrophy.
