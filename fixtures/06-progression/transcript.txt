# Squat: three top-of-range sessions bump `next_target` automatically, no ask.
# Bench Press: a repeat miss asks before a -10% deload; a decline is not
# re-offered on the very next miss.
# Ring Row: a level-axis exercise steps `stage_index`, never `next_target`.
# Assisted Pull-up: an assist set at the top of the range lowers the stored
# `Load` (less assistance = progress), never framed as a rising trend.
# Running: a performance question reads the HRT branch, no writes.
# The mixed-unit Squat history (lb then kg) is ranked in the write-up via
# `read_layer.rank_best`, since ranking is read-only and never a write.
# Overhead Press: a deload accept writes only after a literal `yes`, and a
# second ask left pending across the halt is refused, not written (9vm).
# The pain-triage halt sets `progression: manual`; a bare "I'm fine" routed
# to load-adjust neither clears it, nor lets a session report auto-adjust,
# nor lets a `yes` to a pending deload write under the off switch. A
# malformed set line under the off switch refuses out loud with zero writes:
# neither a traceback nor a silent "Noted." (ayf.12).
