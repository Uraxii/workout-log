# Finding the starting point

In plain words: what somebody can do now, without turning first session into an exam.

## Rule that decides everything else

Test only what would change the program.
Test whose result you already know, or would not act on, is a session spent not training.

## What to take at the start

- Rough working weight on two or three main movements.
- Whatever goal is measured in. Distance, time, rep count, getting off floor unaided.
  Ranked goal gets a dated number before block starts, even a rough one.
- Bodyweight, only if they are comfortable with it and it bears on goal.
- Never body-fat percentage, by any method.
- Body changing for a reason that is not training, hormones most obviously: note you write says so.
  Lean mass falling about 5% in a trans woman's first year is treatment working, not program failing. Muscle gained in a trans man's first year is partly the hormone (Wiik 2020, doi:10.1210/clinem/dgz247).

## How to find a working weight

- Warm up, then add load until a set of about five feels hard but clean. Stop there.
- Entry point, not maximum. Do not hunt a maximum.
- Never estimate a maximum from a set above ten reps.
- First year of training: no testing to a limit.

## When they have no numbers

Normal case.
Light first fortnight finding loads. Say in plan that this is what those two weeks are for, so it does not read as failure.

## Testing again

- At block end, four to six weeks.
- Only what decides next block.
- Same movement, same equipment, same rough time of day. Number measured differently is a different number.

## Writing it down

Every number gets a date. Undated number compares to nothing.
