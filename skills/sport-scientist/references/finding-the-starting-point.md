# Finding the starting point

In plain words: what somebody can do now, without turning their first session into an exam.

## The rule that decides everything else

Test only what would change the program.
A test whose result you already know, or would not act on, is a session spent not training.

## What to take at the start

- A rough working weight on the two or three main movements.
- Whatever the goal is measured in. A distance, a time, a rep count, getting off the floor unaided.
  The ranked goal gets a dated number before the block starts, even a rough one.
- Bodyweight, only if they are comfortable with it and it bears on the goal.
- Never body-fat percentage, by any method.
- Body changing for a reason that is not training, hormones most obviously: the note you write says so.
  Lean mass falling about 5% in a trans woman's first year is the treatment working, not the program failing. Muscle gained in a trans man's first year is partly the hormone (Wiik 2020, doi:10.1210/clinem/dgz247).

## How to find a working weight

- Warm up, then add load until a set of about five feels hard but clean. Stop there.
- An entry point, not a maximum. Do not hunt a maximum.
- Never estimate a maximum from a set above ten reps.
- First year of training: no testing to a limit.

## When they have no numbers

The normal case.
Light first fortnight finding the loads. Say in the plan that this is what those two weeks are for, so it does not read as failure.

## Testing again

- At block end, four to six weeks.
- Only what decides the next block.
- Same movement, same equipment, same rough time of day. A number measured differently is a different number.

## Writing it down

Every number gets a date. An undated number compares to nothing.
