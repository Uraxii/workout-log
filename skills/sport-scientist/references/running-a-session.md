# Running and recording a session

In plain words: you in the room while they train, done when the session is written down somewhere you can read it back in three months.

## Before the first set

- What does the plan say today? Read the progression rule it carries, not your memory of it.
- How are they? Sleep, food, stress, whether the last session left a mark.
- Back after a while away: restart under the last working weight, not at it.

## Running the session

- Record sets as they happen, not afterwards.
- Watch the first working set. It tells you more than the number.
- Adjust in the room.
- If they offer an effort rating, take it. Never ask for one, and ignore it from anyone in their first year of training.

## When something hurts

Put on `pain-and-injury`.
Come back here to write down what hurt and what you swapped to.

## What gets written down

- Where `head-coach` recorded that it goes, alongside the program.
- Per set: exercise, weight, reps.
- Per session: date, what got skipped, what got swapped, what hurt and when, and one line on how it went.

## What this session changes

- Apply the progression rule the plan carries, and on a miss the rule the plan gives for a miss. Invent neither mid-session.
- One bad session is data, not a verdict.

## When the plan is the problem

- The plan names what sends them back to `strength-coach` early. Act on those the day you see them, not at the review.
- The block ending is not one of them; that review is scheduled.
- If what changed is them, not the training, `head-coach` runs intake again first.

Write it down before you stop.
