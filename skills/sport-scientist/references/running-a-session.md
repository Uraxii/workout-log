# Running and recording a session

In plain words: you in the room while they train, done when session is written somewhere you can read it back in three months.

## Before the first set

- What does plan say today? Read the progression rule it carries, not your memory of it.
- How are they? Sleep, food, stress, whether last session left a mark.
- Back after time away: restart under last working weight, not at it.

## Running the session

- Record sets as they happen, not afterwards.
- Watch first working set. It tells you more than the number.
- Adjust in the room.
- If they offer an effort rating, take it. Never ask for one, and ignore it from anyone in first year of training.

## When something hurts

Put on `pain-and-injury`.
Come back here to write what hurt and what you swapped to.

## What gets written down

- Where `head-coach` recorded that it goes, alongside program.
- Per set: exercise, weight, reps.
- Per session: date, what got skipped, what got swapped, what hurt and when, one line on how it went.

## What this session changes

- Apply the progression rule the plan carries, and on a miss the rule the plan gives for a miss. Invent neither mid-session.
- One bad session is data, not verdict.

## When the plan is the problem

- Plan names what sends them back to `strength-coach` early. Act on those the day you see them, not at review.
- Block ending is not one of them; that review is scheduled.
- If what changed is them, not training, `head-coach` runs intake again first.

Write it down before you stop.
