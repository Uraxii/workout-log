# The shape of the cycle

In plain words: how many sessions, what each is for, what sits next to what.

- How many sessions cycle holds and what each is for.
  Name every session by what it is for. A, B, and a bare weekday say nothing.
  Cycle is not always a week. An A and B rotation, every other day, or shift pattern are all cycles, and any dose written per week gets restated per cycle before use.
- Hardest and most technical work first: large before small, multi-joint before single-joint, heavy before light.
  Endurance goal orders itself differently: most sessions easy, one or two hard and kept apart, roughly 80/20 once volume supports it (Seiler 2010, PMID 20861519).
- Hard cardio never lands next to heavy lower body, either side.
  Sport days are hard days.
  Put biggest session furthest from next certain sport day, and name that day in plan.
  If sport supplies hard work, say so in plan.
