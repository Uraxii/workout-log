# Before you write anything

In plain words: where intake becomes training they can start on their next free day.
Done when they have a plan they can read, follow, and argue with.

- `medical-screening` must have been through.
  Flagged: no program to write yet.
  Not asked yet: write block, say at top that it does not start until those four answers come back.
- If they train for a sport, run needs analysis first: sport, level, practice hours a week; which movements and joints it loads; which qualities it pays for; how long a bout lasts and how long rests; which injuries are common in it and in them; then two or three field tests that map to those (NSCA, Essentials of Strength Training and Conditioning, 5th ed.).
  Weight classes: `nutrition` comes before you write.

## What the program is for

- One goal. Several named: make them rank; two unranked goals both get done badly.
- Goal not a training goal yet: turn it into physical qualities that deliver it, and rank those.
- Is there a date? Race, wedding, season, trip. Build backwards from it. No date, no shape.
