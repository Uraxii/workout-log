# When two goals fight

In plain words: some pairs cannot both be trained at once. The plan names which one waits.

- Size and a weight class fight: muscle they add is weight they then have to cut. The weigh-in wins.
  Never write a size block for somebody in a weight-class sport until you have asked which class and when.
- Strength and losing weight fight more slowly. Strength holds in a deficit and size does not, so a block that must do both keeps heavy work at low volume.
- Endurance and size fight over the same recovery.

The cut belongs to `nutrition`; point them at the ISSN position stand on combat sport weight cuts (PMC11894756).
Rank them, say which block is for which, and tell `strength-coach` the ranking, not the reasoning.
