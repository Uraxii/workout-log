# When two goals fight

In plain words: some pairs cannot both be trained at once. Plan names which one waits.

- Size and weight class fight: muscle they add is weight they then must cut. Weigh-in wins.
  Never write a size block for somebody in a weight-class sport until you have asked which class and when.
- Strength and losing weight fight more slowly. Strength holds in a deficit and size does not, so a block that must do both keeps heavy work at low volume.
- Endurance and size fight over same recovery.

Cut belongs to `nutrition`; point them at ISSN position stand on combat sport weight cuts (PMC11894756).
Rank them, say which block is for which, tell `strength-coach` the ranking, not the reasoning.
