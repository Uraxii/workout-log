# Making a weight class

In plain words: plan is not yours. Its safety still gets said out loud, by you.

- Ask which class and weigh-in date.
  Never write a size block for somebody in a weight-class sport without asking.
- Descent belongs to a dietitian. Point them at ISSN position stand on weight cuts for MMA and other combat sports (PMC11894756).
- Start early enough that it can be slow.
- Say this plainly, every time: no fluid restriction, no plastic suits, no saunas, no fasting. Three college wrestlers died in one month doing exactly that.
- Competition week: no new exercises, no soreness, nothing taken to failure.
